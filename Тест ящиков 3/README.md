# Разбиение исходного кода на файлы

Код разбит механически на `partial class Program`, чтобы сохранить существующую логику и упростить первый этап рефакторинга.

## Файлы

- `Program.cs` — поля состояния, константы и объявления WinAPI.
- `Program.Main.cs` — запуск Raylib, инициализация физики, игровой цикл и освобождение ресурсов.
- `Program.Input.cs` — обработка клавиатуры, мыши, перетаскивания и броска коробок.
- `Program.Rendering.cs` — вспомогательная отрисовка текста с тенью.
- `WindowData.cs` — структура с геометрией внешнего окна.

## Как подключить

1. Сделайте резервную копию исходного `Program.cs`.
2. Добавьте все `.cs` файлы из архива в существующий C# проект.
3. Удалите старый `Program.cs`, чтобы не было дублирования типов.
4. Убедитесь, что проект использует те же NuGet-пакеты и настройки, что и исходный проект (Raylib-cs, VelcroPhysics и соответствующий `Microsoft.Xna.Framework`).
5. Соберите проект.

Файлы намеренно оставлены в том же namespace (глобальном), что и исходник. Если в проекте используется namespace, добавьте его одинаково во все файлы.

## Важно

Это первый, безопасный этап разбиения: класс пока остаётся статическим и связанным через общие поля. Следующий этап — выделить `PhysicsWorld`, `InputController`, `RaylibRenderer` и `Win32WindowProvider` в самостоятельные классы с явными зависимостями. Так можно менять архитектуру постепенно, не переписывая всё приложение сразу.
